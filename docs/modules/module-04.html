The story

Where this fits in Marginal Falls

The detective department now faces changing forensic prices. Repeating its choice at different prices produces a demand schedule. The same logic takes the course from a single citizen's shopping list to the town's market demand.

A question to take into class

Which changes move a citizen along a demand curve, and which changes create a new demand curve?
